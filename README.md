# 領収書メール（スマホだけで完結する版）

毎月の出張（第 1 土曜〜月曜）のタクシー・新幹線（スマートEX）・マリンライナー（e5489）の領収書を
スマホの中で集めて、設定した宛先に Gmail で直接送る PWA。サーバー不要（`docs/` を GitHub Pages などで配信するだけ）。

- タクシー：写真アプリから多めに選ぶと、撮影日（EXIF）が出張期間の写真だけ取り込む
- 新幹線・マリンライナー：アプリのボタンでスマートEX / e5489 を開き、領収書を PDF かスクショで保存して追加
- 送信：Gmail API（gmail.send）で直接送信。未設定ならメールアプリへ添付つきで共有
- データ（写真・設定）はスマホの IndexedDB / localStorage のみ。リポジトリに個人情報は入らない

Gmail の OAuth クライアント ID の作り方はアプリの ⚙ に書いてある。
