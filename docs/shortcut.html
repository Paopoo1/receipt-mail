ボタン 1 つで集めて送信

ボタンを押すと、出張期間（第 1 土曜〜月曜）の写真を iPhone が探して文字認識し、「領収」と書かれた写真だけを添付して、そのままメールで送信します。iPhone 標準の「ショートカット」アプリで作ります（最初の 1 回だけ・15 分）。

📲 領収書を集めて送る（作成後に使えます）

しくみ

ボタンを押す →「今月 / 先月」を選ぶ → その月の 第 1 土曜 0 時〜火曜 0 時 の写真と、土曜以降のスクリーンショットを集める → 1 枚ずつ文字認識して 「領収」 を含むものだけ残す → 「N 枚見つかりました。送信しますか？」で 送信 を押す → そのままメール送信

タクシーの紙の領収書の写真も、スマートEX・e5489 の領収書のスクリーンショットも「領収書」と書いてあるので両方拾えます。スクショは後日撮っても拾います。

準備

  1. iPhone の「メール」アプリに、送信に使うアカウント（Yahoo・Gmail など）を設定しておく
    設定 → アプリ → メール → メールアカウント

ショートカットを作る

ショートカット アプリ → 右上の「＋」→ 名前を 領収書を集める に（上のボタンはこの名前で起動します）。下の検索欄でアクション名を入れて追加していきます。

A. どの月か

  1. メニューから選択：項目を 今月 と 先月 に
  2. 「今月」の中に 現在の日付 → 変数を設定 名前 基準
  3. 「先月」の中に 日付を調整（現在の日付 から 1 か月を減算）→ 変数を設定 名前 基準

B. 第 1 土曜を求める

  1. 日付をフォーマット：基準 を カスタム yyyy/MM/01
  2. 入力から日付を取得（↑のテキスト）→ 変数を設定 名前 候補（＝その月の 1 日 0 時）
  3. 繰り返す：回数 7。中に次の 4 つ：
    1. 日付をフォーマット：候補 を カスタム E（曜日が「土」などになる）
    2. もし：フォーマット済みの日付 が「次と等しい」土 → 中に 変数を設定 名前 土曜（値は 候補）
    3. 日付を調整：候補 に 1 日を加算
    4. 変数を設定 名前 候補（値は ↑の調整済みの日付）
  4. 日付を調整：土曜 に 3 日を加算 → 変数を設定 名前 終了（＝火曜 0 時）

C. 写真を集めて文字認識

  1. 写真を検索：フィルタ「作成日」「が次の範囲内」土曜〜終了 → 変数に追加 名前 対象
  2. 写真を検索：フィルタ「スクリーンショットである」がオン、かつ「作成日」「が次の日付より後」終了 → 変数に追加 名前 対象
  3. 各項目を繰り返す：対象。中に：
    1. 画像からテキストを抽出（繰り返し項目）
    2. もし：抽出したテキスト が「次を含む」領収 → 中に 変数に追加「繰り返し項目」を 領収書 に
  4. 数：領収書 の項目数
  5. もし：「数」が「次と等しい」0 → 中に 通知を表示「領収書の写真が見つかりませんでした」と このショートカットを停止

D. 送信

  1. 日付をフォーマット：土曜 を カスタム yyyy年M月
  2. 確認を要求：メッセージ 領収書が「数」枚見つかりました。送信しますか？（キャンセルを押すと止まる。確認もいらなければこのアクションは省略）
  3. メールを送信：
    ・宛先：送り先のアドレス
    ・件名：【領収書】＋↑のフォーマット済みの日付＋ 出張分
    ・本文：お疲れさまです。〇〇です。出張分の領収書（「数」枚）を送付します。よろしくお願いいたします。
    ・添付ファイル：領収書
    ・「作成シートを表示」をオフにする（これでメール画面を開かずにすぐ送信されます）

ボタンの置き場所

  1. このページ上の「📲 領収書を集める」から起動できます（このアプリからも同じボタンがあります）
  2. ホーム画面に直接置くなら：ショートカットを長押し →「共有」→「ホーム画面に追加」
  3. 初回は「写真へのアクセス」「メール」の許可を聞かれるので「許可」

写真が多いと文字認識に数十秒かかります。暗い・斜めの写真は外れることがあるので、最初の 1 回は宛先を自分にして試すと安心です。

手で選んで送りたいとき・金額やメモを付けたいときは、これまでどおりアプリから送れます。
