iPhone で全自動送信

出張の翌日（火曜）の夜に、iPhone が勝手に「土曜 0 時〜今」の写真を文字認識し、「領収」と書かれた写真だけを添付してメールを送ります。iPhone 標準の「ショートカット」アプリで作ります（最初の 1 回だけ・15 分）。

しくみ

毎週火曜 20:00 に起動 → 今日が 4〜10 日（＝第 1 土曜の後の火曜）でなければ終了 → 土曜 0 時以降の写真・スクショを集める → 1 枚ずつ文字認識して 「領収」 を含むものだけ残す → メールで送信

タクシーの紙の領収書の写真も、スマートEX・e5489 の領収書のスクリーンショットも「領収書」と書いてあるので両方拾えます。JR の領収書は火曜の 20 時までにスクショしておいてください。

準備

  1. iPhone の「メール」アプリに、送信に使うアカウント（Yahoo・Gmail など）を設定しておく
    設定 → アプリ → メール → メールアカウント

① ショートカットを作る

ショートカット アプリ → 右上の「＋」→ 名前を「領収書を送る」に。下の検索欄でアクション名を入れて追加していきます。

  1. 現在の日付
  2. 日付をフォーマット：日付のフォーマット「カスタム」、形式 d
  3. 数字：値に ② の「フォーマット済みの日付」を入れる
  4. もし：「数字」が「次より小さい」4 → 中に このショートカットを停止
  5. もし：「数字」が「次より大きい」10 → 中に このショートカットを停止
    （ここまでで「第 1 土曜の後の火曜」以外は何もしない）
  6. 日付を調整：「現在の日付」から 3 日を「減算」（＝土曜）
  7. 日付をフォーマット：上の日付を カスタム yyyy/MM/dd
  8. 入力から日付を取得：上のテキスト（＝土曜 0 時）→ 変数を設定 名前 開始
  9. 写真を検索：フィルタを追加
    ・「作成日」「が次の日付より後」→ 変数 開始
    ・「メディアのタイプ」「が」「写真」
    （スクリーンショットも「写真」に含まれます）
  10. 各項目を繰り返す（写真）→ 中に次の 3 つ：
    1. 画像からテキストを抽出（繰り返し項目）
    2. もし：抽出したテキストが「次を含む」領収
    3. その中に 変数に追加：「繰り返し項目」を変数 領収書 に
  11. 数（項目数を取得）：変数 領収書
  12. もし：「数」が「次と等しい」0 → 中に 通知を表示「領収書の写真が見つかりませんでした」と このショートカットを停止
  13. 日付をフォーマット：変数 開始 を カスタム yyyy年M月
  14. メールを送信：
    ・宛先：送り先のアドレス
    ・件名：【領収書】＋上の「フォーマット済みの日付」＋ 出張分
    ・本文：お疲れさまです。〇〇です。出張分の領収書（「数」 枚）を送付します。よろしくお願いいたします。
    ・添付：変数 領収書（本文の「＋」やアクションを展開して「添付ファイル」に入れる）
    ・「作成シートを表示」をオフにすると確認なしで送信されます

最初の月は「作成シートを表示」をオンにして、送る前に中身を確認するのがおすすめです。

② 毎週火曜に自動で動かす

  1. ショートカット アプリ下の「オートメーション」→「＋」→「時刻」
  2. 時刻 20:00・繰り返し「毎週」・火曜だけ選ぶ
  3. 「すぐに実行」を選び、「実行時に通知」は好みで
  4. 次へ → 「領収書を送る」を選んで完了

第 1 土曜の後の火曜は必ず 4〜10 日になるので、それ以外の週は ① の 4・5 で何もせずに終わります。

試し方

  1. ① の 4・5（日付チェック）を一時的に無効にし、6 の「3 日」を最近の日数にする
  2. 「作成シートを表示」をオン・宛先を自分にして ▶ で実行
  3. 領収書の写真だけが添付されているのを確認したら元に戻す

手で選んで送りたいとき・金額やメモを付けたいときは、これまでどおりアプリから送れます。
